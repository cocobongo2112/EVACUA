# Contribución

1. Crear o asignarse una incidencia del board.
2. Actualizarla a `In-Progress` antes de desarrollar.
3. Crear una rama desde `develop`, por ejemplo `feature/EVACUA-12-escaner-qr`.
4. Realizar commits pequeños con Conventional Commits.
5. Ejecutar formato, análisis y pruebas.
6. Abrir un pull request hacia `develop` y mover la incidencia a `Review`.
7. Obtener una revisión y todos los checks verdes antes del merge.
8. Usar squash merge y mover la incidencia a `Done`.

No se permiten commits directos a `main`. Un hotfix sale de `main`, se integra mediante pull request y después se replica en `develop`.
